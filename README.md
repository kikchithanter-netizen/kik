# Fantom

Одностраничный сайт: почти чёрный фон, белое анимированное дерево, контурный заголовок и плеер на 4 трека.
Сайт полностью статический — бэкенд не нужен, подходит для GitHub Pages.

## Структура

```
fantom-site/
├── index.html                 # разметка страницы
├── assets/
│   ├── css/
│   │   └── style.css          # все стили, анимации, переменные темы
│   ├── js/
│   │   ├── player.js          # плеер: список треков, play/pause, переключение
│   │   └── reveal.js          # анимация появления плейлиста при скролле
│   ├── img/
│   │   ├── avatar.jpg         # фото в рамке
│   │   └── tree.svg           # белое дерево (вектор, заливка #fff)
│   └── audio/
│       ├── 01-kai-angel-pretty-girls.mp3
│       ├── 02-kai-angel-feat-9mice-lipstick.mp3
│       ├── 03-9mice-feat-kai-angel-phoenix.mp3
│       └── 04-9mice-honey-bunny.mp3
├── .nojekyll                  # чтобы GitHub Pages не трогал файлы через Jekyll
├── .gitignore
└── README.md
```

Общий вес: ~8,6 МБ, из них почти всё — аудио. Лимит GitHub на файл — 100 МБ, так что запас огромный.

## Локальный просмотр

Проще всего: открыть `index.html` двойным кликом.

Если нужен локальный сервер (например, чтобы проверить поведение как на хостинге):

```bash
python -m http.server 8000
# затем http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий: **New repository** → имя, например `fantom` → **Public** → **Create repository**.
2. Загрузите файлы: **Add file → Upload files**, перетащите `index.html`, папку `assets`, `README.md` и `.nojekyll` → **Commit changes**.
   - Если папка перетаскивается целиком, `assets` подхватится автоматически.
   - `.nojekyll` — скрытый файл, при перетаскивании папки может не попасть. Тогда: **Add file → Create new file**, имя `.nojekyll`, содержимое оставить пустым → **Commit**.
3. Включите Pages: **Settings → Pages → Build and deployment**
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/fantom/`.

Если вместо ветки хочется Actions — можно выбрать **GitHub Actions** в качестве Source, но для статики достаточно ветки.

## Что где менять

| Что | Где |
| --- | --- |
| Текст, заголовок, состав, ссылки на Steam/Telegram | `index.html` |
| Цвета темы, дерево, свечения, анимации | `assets/css/style.css` (переменные в `:root`) |
| Названия треков и порядок | массив `TRACKS` в `assets/js/player.js` |
| Сами треки | файлы в `assets/audio/` (имя файла должно совпадать с `url` в `TRACKS`) |
| Форма дерева | `assets/img/tree.svg` (заливка `#ffffff`) |
| Фото | `assets/img/avatar.jpg` |

## Особенности

- Анимации отключаются при системной настройке «уменьшить движение» (`prefers-reduced-motion`).
- Шрифты подгружаются с Google Fonts, поэтому без интернета заголовок отрисуется системным шрифтом.
- Автовоспроизведение в браузерах заблокировано: музыка стартует после первого клика/нажатия клавиши — это штатное поведение, так и задумано.
